# Drone-STM32F407-esp32txrx
Bộ điều khiển drone tự chế:tay cầm ESP32 +mạch thu ESP32-S3 +flight controller STM32F407, liên lạc không dây bằng ESP-NOW (WiFi 2.4 GHz), không cần module ELRS/FlySky. DIY drone remote control: ESP32 transmitter, ESP32-S3receiver that emulates an ELRS(CRSF) receiver, and an STM32F407 flight controller with self-leveling and barometric altitude hold
